# きょうの配色カード（palettecard）

季節と気分を選ぶと、3色の配色パレットを表示する小さなツールです。イラストやデザイン、スライドの色選びに迷ったときのヒントに。

## 使い方

- **季節**（春・夏・秋・冬）と**気分**（元気・落ち着く・爽やか・あたたかい）を選んで「配色を見る」を押します。
- パレット名と3色の色見本が表示されます。各色には HEX コードが付いていて、「コピー」ボタンでクリップボードにコピーできます。
- 全16通り（4季節×4気分）の組み合わせにパレットを用意しています。

配色は内蔵の固定データから表示するだけで、外部サービスとは通信しません。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- パレットは16通りの固定データです。色の組み合わせを自動生成するものではありません。
- お気に入り保存や履歴の機能はありません。
- 色の感じ方には個人差があります。実際のデザインではコントラスト比なども確認してください。
